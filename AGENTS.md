# Ordering System - Agent Guide

## Quick Commands

```bash
# Install deps (root)
pnpm install

# Backend
pnpm --filter backend lint
pnpm --filter backend build
pnpm --filter backend test
pnpm --filter backend test:e2e
pnpm --filter backend start:dev

# Frontend
pnpm --filter frontend lint
pnpm --filter frontend build
pnpm --filter frontend dev

# Formatting (root)
pnpm format:check
pnpm format:fix
```

## Architecture

- **Monorepo**: pnpm workspaces with `backend/` and `frontend/`
- **Backend**: NestJS (v11) + Prisma (v7) + PostgreSQL. API prefix: `/api`. Port 3003.
- **Frontend**: React 19 + Vite 8 + Tailwind CSS v4 + shadcn/ui (base-vega style). Path alias `@/` → `src/`.

## Backend Structure

`backend/src/features/` contains domain modules: `auth/`, `categories/`, `orders/`, `supplies/`. Each feature is a NestJS module.

Prisma client is generated to `src/generated/prisma` (excluded from tsconfig compilation). **Must run `prisma generate` before building** after schema changes.

DB is PostgreSQL 16 via Docker (`pnpm --filter backend docker:up`). Seed: `pnpm --filter backend db:seed`.

Config uses `@nestjs/config` with `app.config.ts` pattern. CORS defaults to `http://localhost:5173`.

## Frontend Structure

`frontend/src/pages/` has routes. Admin pages live in `pages/admin/`. State management: zustand. Data fetching: @tanstack/react-query. Forms: react-hook-form + zod. UI: shadcn/ui components.

## CI (GitHub Actions)

CI runs on push/PR to `main`. Checks per package: lint → format:check → build. Backend also runs `prisma generate` before build.

## Conventions

- **Commit messages**: Conventional Commits enforced by commitlint + husky
- **Pre-commit hook**: lint-staged runs ESLint fix + Prettier on `*.{ts,js,tsx,jsx}`
- **Formatting**: Prettier with single quotes, semicolons, 2-space indent, trailing commas (es5)
- **Backend lint**: `@typescript-eslint/no-unused-vars` is error, `no-explicit-any` is warn
- **Frontend lint**: TypeScript ESLint recommended, browser globals

## Gotchas

- `backend/src/generated/` is auto-generated by Prisma — do not edit manually, excluded from prettier/tsconfig
- `frontend/.env` only has `VITE_API_DEV=` (backend dev URL). Backend `.env` needs `DATABASE_URL`, `JWT_SECRET`, `CORS_ORIGINS`
- Backend e2e tests live in `backend/test/` with separate jest config (`jest-e2e.json`)
- The `pnpm-lock.yaml` is present — use `pnpm install`, not npm
